FAQ

Perguntas frequentes.

Respostas rápidas sobre o funcionamento e a distribuição dos agentes.

O Agente Letras é um programa para instalar?

Não. O projeto é distribuído como arquivos de instruções e materiais de apoio para uso com ferramentas de IA compatíveis.

Os agentes têm a mesma função?

Não. Cada agente é direcionado a uma finalidade de escrita diferente.

Posso usar o projeto gratuitamente?

A proposta é disponibilizá-lo gratuitamente. Consulte a licença efetivamente publicada no repositório para conhecer as condições de uso.

Preciso revisar os textos produzidos?

Sim. As respostas de IA podem conter erros, omissões ou alterações de sentido.

Onde encontro versões anteriores?

Após a publicação, elas poderão ser disponibilizadas na área GitHub Releases.
